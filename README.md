Programa de suma en Python
Este programa permite ingresar dos numeros y mostrar la suma de ambos

como funciona?
primero el usuario ingresa el primer numero
segundo el usuario ingresa el segundo numero
despues el codigo  realiza la suma
al final se muestra el resultado en pantalla
Ejemplo

Entrada:
10
5

Salida:
La suma es: 15
